# 智能检验助手 · 安装包

无锡市赢筹智能企业管理咨询有限公司「智能检验助手」的安装包和自动更新文件。这里只放发布文件，不放源码。

- 下载安装包：<https://github.com/wxyczn/yczn-smart-inspect-releases/releases/latest/download/YingChou-SmartInspect-Setup.exe>
  （国内下载慢时用 <https://106.14.200.47/smart-inspect/YingChou-SmartInspect-Setup.exe>）
- 双击按提示安装（默认装在当前用户下，不用管理员权限）；装好后开始菜单和桌面上有「智能检验助手」，在「设置 › 应用」里可以卸载。
- 每次打开会自动检查更新。
- 需要 Windows 10 / 11（64 位）。界面要用的 Microsoft Edge WebView2 运行库 Windows 11 自带，缺的话安装程序会联网装上。
