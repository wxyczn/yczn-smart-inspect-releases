# 智能检验助手 · 安装包

无锡市赢筹智能企业管理咨询有限公司「智能检验助手」的安装包和自动更新清单。这里只放发布文件，不放源码。

- 下载最新版：<https://github.com/wxyczn/yczn-smart-inspect-releases/releases/latest/download/yczn-smart-inspect-win64.zip>
- 解压到自己的文件夹（比如桌面或 D 盘，不要放在 C:\Program Files 下），双击「智能检验助手.exe」运行。
- 装好以后每次打开会自动检查更新。
- 需要 Windows 10 / 11（64 位）和 Microsoft Edge WebView2 运行库（Windows 11 自带）。
